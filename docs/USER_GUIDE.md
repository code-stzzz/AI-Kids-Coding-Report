## 系统简介

本系统是一款专为少儿编程老师设计的Web应用，帮助老师快速生成专业的学生学习报告。

### 核心功能

| 功能 | 说明 |
|------|------|
| 🎯 **班级管理** | 创建班级、添加学生信息 |
| 📚 **课程体系** | 内置 Python/Scratch/C++ 三种课程，U1-U12 共 12 个单元 |
| 📊 **雷达图评分** | 六维度能力可视化评估 |
| 🤖 **AI 智能生成** | 自动生成专业、通俗易懂的报告文案 |
| 🖼️ **海报导出** | 一键生成高清学习报告海报，适合手机分享 |

### 六维能力评估体系

| 维度 | 说明 |
|------|------|
| 代码逻辑掌握 | 理解程序流程、算法思维 |
| 语法规范运用 | 代码规范性、命名规范 |
| 问题排查解决 | Debug 能力、独立解决问题 |
| 课堂专注参与 | 听课状态、互动表现 |
| 创意拓展实现 | 创新思维、作品创意 |
| 知识点复用能力 | 举一反三、知识迁移 |

## 快速开始

### 第一步：注册/登录

1. 访问系统首页
2. 点击右上角「登录/注册」
3. 输入邮箱和密码完成注册
4. 使用账号登录系统

### 第二步：创建班级

1. 进入「班级管理」页面
2. 选择编程语言（Python/Scratch/C++）
3. 点击「+ 添加班级」
4. 填写班级名称（如：Python基础班-A）
5. 保存班级

### 第三步：添加学生

1. 在班级卡片中点击「添加学生」图标
2. 填写学生信息：
   - 姓名（必填）
   - 学号（可选）
   - 学习周期（默认为1）
3. 保存学生信息
4. 可批量添加多个学生

### 第四步：生成报告

1. 返回「首页」
2. 选择编程语言和班级
3. 点击「生成报告」按钮
4. 进入批量编辑页面

## 功能模块详解

### 1. 首页

首页提供快速入口：

- **快速生成报告**：选择语言和班级，一键进入报告生成流程
- **课程管理**：管理课程单元内容
- **班级管理**：管理班级和学生
- **历史报告**：查看已生成的报告

### 2. 班级管理

#### 添加班级
1. 点击顶部的编程语言 Tab 切换语言
2. 点击「+ 添加班级」按钮
3. 填写班级名称和描述

#### 管理学生
- **添加学生**：点击班级卡片中的「添加学生」图标
- **编辑学生**：点击学生信息右侧的编辑图标
- **删除学生**：点击学生信息右侧的删除图标

### 3. 报告生成

#### 选择课程单元
1. 选择本次报告对应的课程单元（U1-U12）
2. 系统会自动显示本阶段和下阶段的学习内容

#### 编辑学生报告
对每个学生进行评估：

**雷达图评分**
- 拖动滑块设置每个维度的分数（1-10分）
- 分数越高表示表现越好

**文字评价**
- **核心进步点**：描述学生本阶段的主要进步
- **待提升点**：委婉指出需要改进的方向
- **竞赛规划**（可选）：如有参赛计划可填写

#### AI 智能生成
点击「AI 生成」按钮，系统将：
1. 根据雷达图分数和文字评价
2. 结合本阶段学习内容
3. 自动生成三段专业文案：
   - 进步表现描述
   - 待提升方向描述
   - 鼓励寄语

### 4. 海报导出

#### 预览报告
点击「预览海报」查看报告效果

#### 导出海报
1. 点击「导出海报」按钮
2. 系统生成高清 PNG 图片（1080×1920px）
3. 自动下载到本地

#### 海报内容
- 学生姓名和学号
- 课程单元名称
- 本阶段学习内容
- 六维能力雷达图
- 核心进步点
- 待提升方向
- AI 生成的评价文案
- 鼓励寄语

## 常见问题

### Q1: 如何修改已生成的报告？
**A**: 进入「历史报告」页面，找到对应学生的报告，点击编辑即可修改。

### Q2: 雷达图分数代表什么？
**A**: 1-10分制，1-3分表示需要加强，4-6分表示表现一般，7-9分表示表现良好，10分表示非常优秀。

### Q3: AI 生成的文案可以修改吗？
**A**: 可以。AI 生成的文案会自动填入文本框，您可以随时修改调整。

### Q4: 海报可以自定义吗？
**A**: 目前海报采用统一的蓝色系教育风格模板，后续版本会支持自定义模板。

### Q5: 如何删除班级？
**A**: 在班级管理页面，点击班级卡片右侧的删除图标。**注意：删除班级会同时删除该班级下的所有学生和报告。**

### Q6: 学习周期是什么？
**A**: 学习周期表示学生当前的学习进度，如第1周期表示刚开始学习，周期数会随着课程进度递增。

### Q7: 支持哪些编程语言？
**A**: 目前支持三种：
- **Python**：适合 8 岁以上，学习真正的编程语言
- **Scratch**：适合 5-8 岁，图形化编程入门
- **C++**：适合有一定基础的学生，面向信息学竞赛
