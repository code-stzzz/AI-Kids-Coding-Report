# 学生结课与报告名单筛选

## 部署

1. 在扣子对应数据库的 SQL 编辑器执行 `scripts/student-status.sql`。如果开发和生产使用不同数据库，需要分别执行。
2. 从 GitHub 拉取本次代码并重新部署。
3. 打开班级管理，将一名学生标记结课；在生成报告页面确认默认在读名单不显示他，切换到已结课后仍能补做报告。之后可恢复在读。

脚本仅新增 `enrollment_status` 和 `completed_at` 字段，现有学生默认为在读，不删除、搬迁或改写已有报告。可重复执行。未执行脚本时原有名单仍可读取，保存结课状态会显示初始化提示。

## 使用

- 在班级管理或生成报告名单中点击“标记结课”或“恢复在读”。状态对应当前学生记录及其班级，不改变其他班级的记录。
- 生成报告默认选择“在读”，可切换“已结课／全部”，按姓名或学号搜索。
- 勾选后点击“为勾选学生制作报告”，逐人进入现有编辑流程。上一个、下一个和快速导航仅包括勾选名单。
- 切换班级、版本、状态或搜索时清空勾选；全选仅包含当前筛选结果。单行生成只打开该学生。
- 结课后的历史报告仍可查看和导出。

这里只提供数据库更新脚本，代码拉取或部署本身不会自动执行 SQL。
