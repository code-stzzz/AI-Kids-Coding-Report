# AI 报告提示词管理

## 部署

在扣子项目对应数据库执行 `scripts/ai-report-prompts.sql`，开发与生产数据库若不同需分别执行。随后拉取代码并部署。脚本只增加按账号存储的提示词表，可重复执行，不改动学生、报告或 AI 接口配置。

未建表时仍使用系统默认提示词生成报告；管理页面提示先初始化，不能保存自定义内容。数据库更新尚未由本地代码自动执行。

## 使用

首页 → AI 接口 → 报告生成提示词。修改写作要求并保存，后续生成即使用新规则。支持查看默认内容、恢复默认、重新加载。保存冲突时先备份当前草稿，再重新加载并合并修改。

可以修改角色、语气、篇幅、各段要求和学习建议，不需要写代码或填写学生信息。姓名、语言、课程、能力评价和教师观察会自动带入。系统保留报告六个输出字段，以便页面正常解析。生成结果仍由现有校验器检查，错误结果不会替换已保存的报告。

提示词仅作用于当前登录账号，与所选 AI 服务商无关，扣子默认模型及其他兼容接口都共用这份设置。无需配置 API 密钥加密环境变量即可管理提示词。已有报告不会被批量修改。
